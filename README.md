A **Model Context Protocol (MCP) server** that connects AI assistants (Claude Desktop, VS Code, Cursor, Windsurf, Goose, etc.) with the **Slovak Cadastral Portal (Úrad geodézie, kartografie a katastra SR)**.  
This server allows LLMs to fetch structured property information, generate reports, and open cadastral data directly in the user’s browser (Chrome).  

---

## ✨ Key Features
- **Retrieve property information**  
  - For **C (CKN)** and **E (EKN)** parcels.  
  - Ownership records, buildings, land use classification, legal encumbrances.  

- **Export parcel data to PDF**  
  - Automatically generate a clean, human-readable summary of property information.  

- **Parse council meeting minutes**  
  - Detect parcel numbers directly from PDF/DOCX minutes.  
  - Create ready-to-use “property packets” for each request (e.g. land sale, swap, lease).  

- **Open directly in Chrome**  
  - With one command, launch the official cadastral portal or ZBGIS map for the selected parcel.  

- **LLM-friendly interface**  
  - All data provided as structured JSON — no scraping of screenshots.  
  - Deterministic tools, safe to use in automated workflows.  

---

## 📋 Requirements
- **Node.js 18+**  
- An MCP-compatible client such as:  
  - Claude Desktop (recommended)  
  - VS Code / Cursor / Windsurf / Goose   

---

## 🚀 Use Case: Municipalities & Transparency
This MCP is designed especially for **mayors, councils, and local communities**:  
- Quickly prepare **complete land sale/lease packets** for council meetings.  
- Ensure **transparency** by linking every agenda item with actual cadastral data.  
- Save time for small municipalities by automating repetitive lookups.  

---

👉 With this MCP, an AI assistant becomes a **“cadastral clerk” inside your desktop app**, ready to pull land registry data, generate reports, and open maps — all on demand.

**Persistent profile**

All the logged in information will be stored in the persistent profile, you can delete it between sessions if you'd like to clear the offline state.
Persistent profile is located at the following locations and you can override it with the `--user-data-dir` argument.

```bash
# Windows
%USERPROFILE%\AppData\Local\ms-playwright\mcp-{channel}-profile

# macOS
- ~/Library/Caches/ms-playwright/mcp-{channel}-profile

# Linux
- ~/.cache/ms-playwright/mcp-{channel}-profile
```


**Browser Extension**

The Playwright MCP Chrome Extension allows you to connect to existing browser tabs and leverage your logged-in sessions and browser state. See [extension/README.md](extension/README.md) for installation and setup instructions.

### Configuration file

The Playwright MCP server can be configured using a JSON configuration file. You can specify the configuration file
using the `--config` command line option:

```bash
npx skgeodesy-mcp@latest --config path/to/config.json
```

<details>
<summary>Configuration file schema</summary>

```typescript
{
  // Browser configuration
  browser?: {
    // Browser type to use (chromium, firefox, or webkit)
    browserName?: 'chromium' | 'firefox' | 'webkit';

    // Keep the browser profile in memory, do not save it to disk.
    isolated?: boolean;

    // Path to user data directory for browser profile persistence
    userDataDir?: string;

    // Browser launch options (see Playwright docs)
    // @see https://playwright.dev/docs/api/class-browsertype#browser-type-launch
    launchOptions?: {
      channel?: string;        // Browser channel (e.g. 'chrome')
      headless?: boolean;      // Run in headless mode
      executablePath?: string; // Path to browser executable
      // ... other Playwright launch options
    };

    // Browser context options
    // @see https://playwright.dev/docs/api/class-browser#browser-new-context
    contextOptions?: {
      viewport?: { width: number, height: number };
      // ... other Playwright context options
    };

    // CDP endpoint for connecting to existing browser
    cdpEndpoint?: string;

    // Remote Playwright server endpoint
    remoteEndpoint?: string;
  },

  // Server configuration
  server?: {
    port?: number;  // Port to listen on
    host?: string;  // Host to bind to (default: localhost)
  },

  // List of additional capabilities
  capabilities?: Array<
    'tabs' |    // Tab management
    'install' | // Browser installation
    'pdf' |     // PDF generation
    'vision' |  // Coordinate-based interactions
  >;

  // Directory for output files
  outputDir?: string;

  // Network configuration
  network?: {
    // List of origins to allow the browser to request. Default is to allow all. Origins matching both `allowedOrigins` and `blockedOrigins` will be blocked.
    allowedOrigins?: string[];

    // List of origins to block the browser to request. Origins matching both `allowedOrigins` and `blockedOrigins` will be blocked.
    blockedOrigins?: string[];
  };
 
  /**
   * Whether to send image responses to the client. Can be "allow" or "omit". 
   * Defaults to "allow".
   */
  imageResponses?: 'allow' | 'omit';
}
```
